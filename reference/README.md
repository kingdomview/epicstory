# Reference — read-only

`herowithin-v0.1.7-draft/` is ChatGPT's last child theme, imported verbatim as the historical
baseline for the rebuild. **Do not edit or activate it** — it carries the editability and
CSS-cascade problems the v2.0.0 rebuild (`../themes/epicstory/`) exists to fix. Kept here so
the approved visual direction and prior implementation stay browsable.

The The Epic Story of God Formation Matrix Core plugin (v0.7.2) is NOT included here — export it from the
live site into `../plugins/` and audit it independently. It owns the `hw_coordinate` CPT and
the 144 Formation Coordinates; its logic must never move into the theme.
